# ITSB FIND — Sistem Informasi Lost & Found Kampus ITSB

**ITSB FIND** merupakan aplikasi berbasis web yang dikembangkan sebagai proyek tugas kelompok mahasiswa Institut Teknologi Sains Bandung (ITSB). Aplikasi ini dirancang untuk membantu proses pelaporan, pencarian, pendataan, dan pengelolaan barang hilang maupun barang temuan di lingkungan kampus.

Melalui ITSB FIND, mahasiswa, dosen, tamu, dan staf kampus dapat mengakses informasi barang hilang dan temuan secara lebih terstruktur. Pengelolaan data serta proses verifikasi dan pengembalian barang dilakukan oleh petugas Satpam melalui halaman khusus.

## Tujuan Proyek

Proyek ini bertujuan untuk menyediakan alternatif sistem informasi yang mempermudah civitas akademika dalam menemukan informasi barang hilang maupun barang temuan, sekaligus membantu petugas kampus dalam mengelola proses administrasi barang.

## Fitur Utama

- **Pelaporan Barang Hilang:** Pengguna dapat melaporkan barang yang hilang beserta informasi dan foto pendukung.
- **Pelaporan Barang Temuan:** Pengguna dapat menginformasikan barang yang ditemukan di lingkungan kampus.
- **Pencarian dan Filter:** Memudahkan pengguna menemukan informasi barang berdasarkan kategori dan informasi lainnya.
- **Mode Tamu:** Pengunjung dapat melihat daftar barang tanpa harus membuat akun.
- **Dashboard Satpam:** Menyediakan pengelolaan laporan, konfirmasi barang temuan, dan proses pengembalian barang.
- **Dokumentasi Pengembalian:** Petugas dapat mencatat proses serah terima barang beserta foto dokumentasi.
- **Profil Tim:** Menampilkan informasi anggota kelompok pengembang.

## Teknologi yang Digunakan

- Python
- Flask
- SQLite
- HTML, CSS, dan JavaScript
- Pillow
- EmailJS (integrasi untuk fitur email)
